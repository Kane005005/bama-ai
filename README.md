# Bama AI 🇲🇱

Bama AI is an open-source research project to build a **native Bamanankan voice AI**.

The goal is not to build a French-to-Bamanankan translator. The long-term goal is an AI that can listen to Bamanankan speech, understand Bamanankan in context, reason without requiring French as an intermediate language, and respond naturally in Bamanankan.

## Vision

> Teach an AI to live in Bamanankan, not simply translate Bamanankan.

The project investigates the full voice-AI stack:

**Speech → Bamanankan understanding → reasoning → Bamanankan speech**

This is a long-term research and engineering project. We document successes, failures, experiments, datasets, benchmarks and design decisions openly.

## Principles

1. Native-first: Bamanankan is a first-class language.
2. Evidence before implementation.
3. Data quality, provenance and consent are engineering requirements.
4. Experiments should be reproducible where possible.
5. Speakers, linguists, researchers and developers should be able to contribute.
6. Voice data must be collected and used ethically.
7. No premature architecture lock-in.
