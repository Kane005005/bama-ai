# Contributing to Bama AI

Thank you for helping build Bamanankan AI infrastructure.

## Who can contribute?

We welcome Bamanankan speakers, linguists, language teachers, developers, ML researchers, speech engineers, data engineers, annotators, testers, documentation contributors and people who can identify existing resources.

## Before contributing

Please read:

- [README.md](README.md)
- [ROADMAP.md](ROADMAP.md)
- [DATASET.md](DATASET.md)
- [docs/data-governance.md](docs/data-governance.md)

## Contribution rules

1. Do not upload private, copyrighted or restricted data without permission.
2. Do not upload someone's voice without appropriate consent.
3. Document the source and license of external material.
4. Keep experiments reproducible.
5. Separate observations from assumptions.
6. Document failures as carefully as successes.
7. Avoid changing project architecture without discussion.
8. Prefer small, reviewable changes.

## Pull requests

Explain:

- What changed?
- Why?
- What evidence supports the change?
- How was it tested?
- Are there data, licensing or privacy implications?

For model/data changes, include evaluation results when available.

## Language contributions

Native Bamanankan speakers are especially valuable contributors. When possible, provide context rather than isolated word translations.

A useful contribution can include the sentence, natural meaning, alternative forms, context, and pronunciation/audio when consent permits.

## Code of conduct

Be respectful. This project is intended to grow through collaboration between technical and language communities.
