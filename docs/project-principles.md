# Project Principles

## 1. Native Bamanankan first
Bama AI is not primarily a translation project. Translation can help research, but the target system should progressively develop direct competence in Bamanankan.

## 2. Voice is first-class
The project is fundamentally about speech. Text resources support language understanding, but the end goal includes listening and speaking.

## 3. Research before scale
Establish small, measurable baselines before large-scale training.

## 4. Measure what matters
A model that produces text but misunderstands meaning, or a voice that pronounces words incorrectly, is not considered solved simply because a demo works.

## 5. Native-speaker evaluation
Technical metrics are necessary but insufficient. Native Bamanankan speakers must participate in evaluating naturalness, meaning and appropriateness.

## 6. Open documentation
Show the real research process, including failed approaches and limitations.

## 7. Reproducibility
Important results should contain enough information to understand how they were produced.

## 8. Community value
The project should create useful infrastructure for the Bamanankan ecosystem rather than extracting language data without giving value back.

## 9. No premature promises
We will not claim the AI understands Bamanankan natively until experiments demonstrate the relevant capabilities.

## 10. Build patiently
A small trustworthy dataset and a well-measured baseline are more valuable than a flashy but irreproducible demo.
